TinyGo.PathFinder

PathFinder

3D pathfinding using Godot's NavigationAgent3D. Returns a direction — you apply the velocity.

Requirements

Before using PathFinder, make sure your scene has:

  • A NavigationRegion3D node with a baked NavigationMesh.
  • A NavigationAgent3D node as a direct child of your character.
Godot 4.7.1: Navigation regions update asynchronously. PathFinder handles this automatically — it waits one physics frame before setting the target so the nav map has time to sync.

Setup

Add using TinyGo; at the top of your script. Create a PathFinder instance, assign the required properties in _Ready(), then call Init().

using Godot;
using TinyGo;

internal partial class ChaseYou : CharacterBody3D
{
    [Export] public NavigationAgent3D agent;
    [Export] public Node3D target;
    [Export] public float speed = 10.0f;

    public PathFinder _Agent = new PathFinder();

    public override void _Ready()
    {
        _Agent.Self   = this;
        _Agent.Target = target;
        _Agent.Agent  = agent;
        _Agent.Init();
    }

    public override void _PhysicsProcess(double delta)
    {
        base._PhysicsProcess(delta);
        _Agent.Update();
        Velocity = _Agent.Direction_To_Target * speed;
        MoveAndSlide();
    }
}

Properties

PropertyTypeDescription
SelfCharacterBody3Drequired The character node this PathFinder belongs to.
TargetNode3Drequired The node to navigate toward.
AgentNavigationAgent3Drequired The NavigationAgent3D child of your character.
DesireDistancefloatoptional How close to each path point before moving to the next. Default: 1.0f
TargetDesireDistancefloatoptional How close to the final target before stopping. Default: 1.0f
Direction_To_TargetVector3Read-only. The direction toward the next path position. Multiply by speed and assign to Velocity.

Methods

MethodDescription
Init()Call once in _Ready() after setting all required properties.
Update()Call every _PhysicsProcess() frame. Updates Direction_To_Target.

Notes

  • The NavigationRegion3D must have a baked mesh before the game runs. PathFinder does not bake at runtime.
  • Use optimized, low-polygon navigation meshes for best performance.
  • Direction_To_Target is a normalized Vector3. Multiply by your desired speed before assigning to Velocity.
  • If your character should also have gravity, apply it separately to the Y component of Velocity before calling MoveAndSlide().
