TinyGo.Chunk

Chunk

Loads and unloads scenes based on player distance. One Chunk instance per scene.

How it works

Each Chunk monitors the distance between the player and a location node. When the player gets close enough, the scene is added to the tree. When they move away, it's removed and freed.

Preloading instantiates the scene before it's visible, so it's ready the moment the player enters range — no pop-in.

── far away ──────────────────── close ──>
PreLoad_Distance ChunkDistance
unloaded [ instantiate ] [ add to tree ]
preloaded in mem visible in game

Setup

Create one Chunk instance per scene you want to stream. Assign properties in _Ready() and call Update() every process frame.

using Godot;
using TinyGo;

internal partial class MyChunk : Node
{
    [Export] public PackedScene chunk;
    [Export] public CharacterBody3D player;
    [Export] public Node3D location;

    public Chunk _Chunk = new Chunk();

    public override void _Ready()
    {
        _Chunk.chunk         = chunk;
        _Chunk.Player        = player;
        _Chunk.LocationNode  = location;
        _Chunk.ChunkDistance  = 20.0f;

        // Optional — preload before entering range
        _Chunk.EnablePreLoad_Chunk = true;
        _Chunk.PreLoad_Distance    = 30.0f; // must be > ChunkDistance
    }

    public override void _Process(double delta)
    {
        _Chunk.Update();
    }
}

Multiple chunks

Create one script per chunk, or manage multiple Chunk instances in a single node. Each instance is independent.

// Two chunks in one manager node
public Chunk _ChunkA = new Chunk();
public Chunk _ChunkB = new Chunk();

public override void _Process(double delta)
{
    _ChunkA.Update();
    _ChunkB.Update();
}

Properties

PropertyTypeDescription
chunkPackedScenerequired The scene to load and unload.
PlayerNode3Drequired The player node. Distance is measured from here.
LocationNodeNode3Drequired Where the chunk is placed in the world. The loaded scene is added as a child of this node.
ChunkDistancefloatrequired Distance at which the chunk is added to the scene tree. Default: 20.0f
EnablePreLoad_Chunkbooloptional Enable preloading. Default: false
PreLoad_Distancefloatoptional Distance at which the scene is instantiated in memory. Must be greater than ChunkDistance. Default: 30.0f

Methods

MethodDescription
Update()Call every _Process() frame. Handles all load, unload, and preload logic.

Notes

  • PreLoad_Distance must always be larger than ChunkDistance. If they're equal or reversed, preloading will not work correctly.
  • Keep chunk scenes optimized. Heavy meshes with large textures will cause frame drops on load regardless of preloading, because instantiation still happens on the main thread.
  • Use _Process, not _PhysicsProcess, for chunk updates. Distance checks don't need physics precision.
  • The LocationNode is the parent for the loaded scene. Position your LocationNode where you want the chunk to appear in the world.
Performance tip: Test your chunk scenes with the Godot profiler. A scene that freezes the frame on load is too heavy — reduce polygon count or compress textures before shipping.
